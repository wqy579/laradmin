一、系统简介

LarAdmin 是一套进销存（ERP）后台管理系统，涵盖商品资料与分类、采购/销售订单、库存（出入库/调拨/退货/盘点）、客户与供应商、车辆与路线、员工与拜访记录、财务收支等业务模块，并配套完整的 RBAC 权限体系。

三、技术栈

  • 后端：Laravel 12 + Swoole 常驻内存服务
  • 前端：Vue 3 + Element Plus + VXE Table
  • 认证：JWT 令牌认证 + RBAC 角色权限

系统源代码与运维部署文档存放于内部代码仓库，不对外公开。使用中遇到问题，请通过内部渠道联系维护人员。
